2. Step-by-Step: Database Backup (From Server to Local PC)

Step 1: Open Database Web Terminal
  1. Log in to Easypanel at http://129.121.128.205:3000
  2. Click on project jit_support → click service jit (Postgres)
  3. Click Console (or Terminal) in the top tabs → click Bash
  4. You will see the root prompt: root@...:/#
Step 2: Generate Compressed PostgreSQL Dump

Run this command inside the terminal prompt:

pg_dump -U $POSTGRES_USER $POSTGRES_DB | gzip > /tmp/db_backup.sql.gz && echo "Backup ready!"

Note: Uses the container's built-in $POSTGRES_USER and $POSTGRES_DB environment variables automatically.

Step 3: Upload Backup to Secure Transfer Endpoint

Send the backup to the temporary transfer service:

curl -F "file=@/tmp/db_backup.sql.gz" https://tmpfiles.org/api/v1/upload

The server returns JSON output like:

{"status":"success","data":{"url":"https://tmpfiles.org/XXXXXX/db_backup.sql.gz"}}
Step 4: Download the File to Your Windows System
  1. Take the URL returned in Step 3.
  2. Insert /dl/ immediately after tmpfiles.org:
    • Original link: https://tmpfiles.org/XXXXXX/db_backup.sql.gz
    • Direct download link: https://tmpfiles.org/dl/XXXXXX/db_backup.sql.gz
  3. Paste the direct download link into Chrome or Edge. The file will save directly to your Downloads folder.
Step 5: Clean Up the Server

In the terminal, remove the temporary backup file:

rm /tmp/db_backup.sql.gz

3. Extracting and Verifying the Backup on Windows

Your downloaded file is compressed with gzip (db_backup.sql.gz).

Option A: Extract using 7-Zip / WinRAR

  • Right-click db_backup.sql.gz → 7-Zip → Extract Here.
  • It will produce the raw db_backup.sql file.

Option B: Extract using Windows PowerShell

$in = "$HOME\Downloads\db_backup.sql.gz"
$out = "$HOME\Downloads\db_backup.sql"
$src = [System.IO.File]::OpenRead($in)
$dst = [System.IO.File]::Create($out)
$gz = New-Object System.IO.Compression.GZipStream($src, [System.IO.Compression.CompressionMode]::Decompress)
$gz.CopyTo($dst)
$gz.Dispose(); $dst.Dispose(); $src.Dispose()
Write-Host "Extracted successfully to $out"

4. Step-by-Step: Backing Up File Attachments & Manuals

  1. In Easypanel, open project jit_support → click service github (App container).
  2. Click Console → Bash.
  3. Archive all ticket attachments and uploaded manuals: 
    tar -czf /tmp/attachments_backup.tar.gz -C /app/data attachments
  4. Upload and download: 
    curl -F "file=@/tmp/attachments_backup.tar.gz" https://tmpfiles.org/api/v1/upload
  5. Add /dl/ to the download URL and save to your PC.
  6. Clean up: 
    rm /tmp/attachments_backup.tar.gz

5. Disaster Recovery / Restoring the Database

To restore your database dump into PostgreSQL:

  1. In Easypanel → jit service → Console → Bash.
  2. If restoring from .sql.gz: 
    gunzip -c /tmp/db_backup.sql.gz | psql -U $POSTGRES_USER -d $POSTGRES_DB
  3. If restoring from uncompressed .sql: 
    psql -U $POSTGRES_USER -d $POSTGRES_DB < /tmp/db_backup.sql
  4. Verify table count and restoration: 
    psql -U $POSTGRES_USER -d $POSTGRES_DB -c "\dt"

6. Quick Troubleshooting

Error / Symptom Root Cause Solution
curl: command not found Curl is missing from container Run apt-get update && apt-get install -y curl once.
role "postgres" does not exist Using hardcoded default user Always use $POSTGRES_USER variable in the command.
pg_dump: command not found Terminal opened in app container Switch console to the jit (Postgres) service.
Browser downloads HTML page instead of file Missing direct download prefix Add /dl/ after tmpfiles.org in the link.
