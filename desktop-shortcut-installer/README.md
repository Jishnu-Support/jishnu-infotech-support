# Jishnu Infotech Support desktop shortcut installer

This installer creates **Jishnu Infotech Support** on the current Windows user's Desktop. Double-clicking it opens `https://jitsupport.jishnuinfotech.com` in the user's default browser.

## Install

1. Extract `Jishnu-Support-Desktop-Shortcut-Installer.zip`.
2. Open the extracted folder.
3. Double-click `Install-JishnuSupportShortcut.cmd` and wait for the success message.
4. Double-click **Jishnu Infotech Support** on the Desktop to open the portal login page.

The installer only creates or replaces that desktop shortcut. It does not install a browser add-on or collect user data. The portal URL is set in `Install-JishnuSupportShortcut.ps1`.
